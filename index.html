Sistema de Vendas

Aplicação web voltada à organização de vendas e cadastros, criada para praticar desenvolvimento Front-end e boas práticas com Git e GitHub.

Ver Funcionalidades GitHub

Sobre o Projeto

Projeto desenvolvido para consolidar fundamentos de desenvolvimento web, responsividade, manipulação da interface e versionamento de código com Git e GitHub.

Funcionalidades

Gestão de Vendas

Registro e acompanhamento de pedidos e valores de forma simples e objetiva.

Clientes e Produtos

Estrutura pensada para organizar itens, clientes e consultas com clareza.

Interface Responsiva

Layout adaptável para desktops, tablets e celulares, com foco em usabilidade.

Tecnologias Utilizadas

  • HTML5 Semântico
  • CSS3 (Flexbox e Grid)
  • JavaScript
  • Git & GitHub
